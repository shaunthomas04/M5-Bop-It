# M5-Bop-It

A Bop-It-style party game played on an M5Stack device connected to your phone over Bluetooth.

---

## Setup

Upload the M5Stack firmware to your M5Stack device. Once uploaded, the device will display a "Connect to phone" screen and is ready to pair.

---

## How to Play

1. Open the M5-Bop-It app on your phone and connect to the M5Stack via Bluetooth.
2. Enter the M5's device name into the phone app (default ShaunM5) and scan for M5.
2. The game will send a command to a player — their name and action appear on the M5Stack screen.
3. That player must complete the action **before time runs out**.
4. If they succeed, the game moves on. If they're too slow, they're out!
5. The last player remaining wins!
---

## Modes
 
### Random Mode
Each player is given a random command to complete before time runs out. No one knows what's coming next — stay sharp!
 
### Taskmaster Mode
One person takes control as the Taskmaster and manually chooses which command each player must perform.
 
---

## Commands

| Command | What to Do |
|---------|------------|
| 🔴 **BOP IT** | Tap the red circle on the screen |
| 🟡 **SLIDE IT** | Drag the yellow slider all the way to the right |
| 🔵 **TWIST IT** | Rotate the device sideways (roll it left or right) |
| 🟢 **SHAKE IT** | Shake the device! |

---

Good luck, and don't be too slow.
